# ML-150

A hands-on journey through the **ML-150** machine learning problems from Papers With Code.

This repository documents my progress as I work through the ML-150 problem set, focusing on understanding the underlying mathematical concepts, computational thinking, numerical stability, and practical implementation of machine learning techniques.

The goal is not simply to complete the problems, but to understand **why the solutions work, where they are useful, and how the underlying ideas appear in real machine learning systems.**

## What This Repository Covers

The problems span different areas of machine learning and numerical computing, including:

* Mathematical foundations
* Numerical computation
* Probability and statistics
* Optimization
* Machine learning algorithms
* Neural network fundamentals
* Numerical stability
* Other important ML building blocks

Each problem is approached as an opportunity to understand a specific concept rather than simply writing a working solution.

## Learning Approach

For each problem, the focus is on:

1. Understanding the problem and its mathematical formulation
2. Breaking the concept into smaller steps
3. Implementing the solution using appropriate tools
4. Considering computational efficiency and numerical stability
5. Testing the solution with different inputs and edge cases
6. Understanding where the concept is used in machine learning
